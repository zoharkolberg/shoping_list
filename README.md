# Shopping List

אפליקציה לניהול רשימות קניות ומשימות אישיות ומשותפות.

## Architecture

- HTML, CSS and Vanilla JavaScript
- GitHub Pages
- Google Drive and Google Sheets
- IndexedDB
- Offline-first PWA
- Hebrew RTL interface
- No backend server

## Development

Development is performed using OpenAI Codex.

Current phase: Proof of Concept (POC).

Full implementation will begin only after successful completion of the POC.
